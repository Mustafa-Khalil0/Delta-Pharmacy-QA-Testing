# Delta Pharmacy App – Manual QA Testing

## Project Overview
A manual software testing project focused on evaluating the functionality, reliability, and usability of a pharmacy web application.

## Testing Scope
- Registration and Login
- Dashboard
- Products and Orders
- Prescriptions
- Support and Chat
- Notifications and Analytics
- User Management

## Testing Activities
- Functional Testing
- Negative Testing
- Boundary Value Analysis
- Equivalence Partitioning
- Role-Based Access Testing
- Responsive UI Testing
- Security-Related Input Testing

## User Roles
- Customer
- Pharmacist
- Admin

## Defect Reporting
Identified and documented issues related to:
- Missing input validation.
- Incorrect session and role switching.
- Notification display inconsistencies.

## Tools
- Excel – Test Case Documentation
- Postman – API Testing (if used in this project)
- SQL – Database Validation (if used in this project)

## Project Deliverables
- Test Cases
- Test Execution Results
- Defect Reports
- Testing Summary
